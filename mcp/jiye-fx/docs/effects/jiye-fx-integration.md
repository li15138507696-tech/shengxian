# 几页特效工坊 MCP：安装与资料核对

## 安装范围

- MCP 服务：`jiye-fx` 1.2.0，入口 `mcp/jiye-fx/server.mjs`，使用随包提供的 Node 依赖。
- 服务根目录通过 `JIYE_FX_ROOT` 指向本项目根目录；MCP 配置写入当前 Codex 用户配置。
- V5.4 特效与贴图资料已经在 `素材/guzrlevelupdemoV5.4-特效与贴图/`。本次压缩包中 647 个文件都与项目内副本逐个哈希相同，因此不重复覆盖。
- `data/SKILL.md` 是这套素材的技术索引，`data/index.json` 是机器可查的特效资产摘要。完整 shader、动画和模型仍以素材目录里的原文件为准。

## 已核对的资料结构

这套资料把效果分成三条并行路线：Veil 的几何/后处理资源、原版核心 Shader，以及 GeckoLib 几何模型与动画。特效索引覆盖 122 个 program、94 个 rendertype、32 个 post、4 个 framebuffer 和 1 个 include；另有 12 组模型/动画、177 张贴图与 2 个 GZSM 模型。

对本项目的传奇仙蛊素材最有参考价值的是：

- `immortal_gu_item_aura` 有内外两层轮廓辉光，使用 10 组循环配色和星点；这是动态特效参考，不是 16×16 贴图规范。
- `spring_autumn_time_river` 是带双趟 bloom 的时间丝带效果，可作为春秋蝉后续灵光/时间流特效参考。
- `eat_strength.geo.json` 与对应动画是现有力道蛊的三维参考，纹理为 64×64；它不等于原著《人祖传》中无形的力量蛊外貌，也不能直接当成 16×16 图标。

这些资源说明了如何做模型层次和灵光。它们不证明书中没有明确外形的蛊虫长什么样；智慧蛊、力量蛊的像素外观仍需标成设计补形。

## 服务工具与写入位置

- `fx_jiye`：查找、查看或复制已有 V5.4 特效及其依赖。
- `fx_plan`、`fx_create`、`fx_validate`：规划、生成并检查 Veil 特效包。默认输出到项目内 `特效工坊/<name>/`。
- `fx_space`、`fx_schema`、`fx_api`、`fx_mechanism`、`fx_recipes`、`fx_resource`：查询坐标、资源格式、API、渲染机制、配方和资料。
- `fx_java`：输出 Java 调用代码；仅在显式写入时写到项目内输出目录。

该 MCP 的素材复制默认目标原本假定仓库内还有一层 `shengxian/`。本项目根目录已经是升仙工程，因此安装时已将默认目标修正为 `src/main/resources/assets/`。复制工具默认不覆盖已存在的文件；使用前仍应先查看依赖和冲突清单。

## 适用边界

这些文件来自用户提供的 V5.4 资料包，属于工程实现和美术参考。原著设定仍以小说明确描写为准；shader 的命名、颜色、几何和动画都不应被当作小说事实。
