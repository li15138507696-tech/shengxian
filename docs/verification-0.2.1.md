# 0.2.1 三气汇聚光效交付记录

## 改动

- 新增由 jiye-fx 生成并改成项目调色的 Veil `entity_aura` 资源：三道淡金、青绿、赤霞流带和三道玉色环带，含第二趟 bloom。
- `qi` 服务端消息现在带实体 ID；客户端按实体挂载光效，显式停止和超时都会在 12 tick 内淡出。payload 协议版本升到 `2`。
- `neoforge.mods.toml` 声明 Veil 4.5.2+ 为客户端必需依赖，服务端不需要；Veil JAR 不打进升仙产物。
- 升仙 StartGate、阶段数据、本体字段和仙蛊物品没有更改。

## 限制与核验

- 当前工程未在本地运行配置中安装 Veil，因此本轮不能确认游戏内实际画面与驱动 shader 编译；安装 NeoForge 版 Veil 4.5.2+ 后，F3+T 可热重载资源。
- 本地验证只覆盖 Java 编译、JAR 元数据/资源清单和工坊静态 schema 校验；未运行行为测试，也未启动游戏。
- 三气颜色与仙窍环造型是游戏美术映射，不宣称来自原著明文。
