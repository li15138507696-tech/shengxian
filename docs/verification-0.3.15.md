# 0.3.15 离线验证记录：限制催蛊观察内存

日期：2026-10-28。基于 0.3.14 的四条本体观察钩子，保留旧 JAR 并递增新产物。

## 变更

独立代码审查发现，0.3.14 虽限制每个 owner 的事件条数，但 owner 映射和独立序号 Map 会随长期在线服务器的新参与者增长。0.3.15 将 owner 序号与事件合并成同一个 access-ordered LRU 状态：

- 默认最多保留 4096 个最近使用的 owner。
- 每位 owner 最多保留 64 条事件。
- owner 超过上限时，最久未访问的 owner 连同其事件、去重键和序号一起淘汰。
- 淘汰后的玩家再次参与时从序号 1 开始；账本仅用于非权威观察，不参与游戏结果。
- 服务器启停清理仍清空全部临时数据。
