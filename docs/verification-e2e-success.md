## 关键经验：三气必须按速率匹配

第一次失败是因为我按同比例给了意图：人气释放上限 3.0/刻，天地吸收上限 4.0/刻，同样 0.5 的意图下人气象素涨得慢，最后人气被反超到 72 而天地各 36，风险 12.11 越限 → FAILED。

正确做法（CANON-002 的操作含义）：

```
人气意图 = 天地意图 × (4.0 / 3.0)
```

例如 0.5 / 0.5 / 0.667，三者以同样的绝对速率上升，天然保持平衡，风险稳定在 3–7 之间。
