# 0.3.57 有形、有体积的天地异象

日期：2026-11-02。用户明确要求不使用粒子堆叠，改用有形状、体积、质感的大型三维特效。

## 表现

- GrandRitualMesh：约40格高的三条封闭厚气流，天青、地碧、人金；中心线与粗细平滑变化，沿自身路径运动。
- 云冠：平均半径22格，具有起伏、厚度与表面流纹，取消规则金条装饰；头顶另叠加约80格宽、24格厚的真实光线步进体积云。
- 地脉：半径约11–22格的多层连续岩脊，保留中央活动区；不放置真实方块、不新增伤害和碰撞。
- 使用闭合曲面、表面UV、原创流纹纹理、法线与面向光照实现轮廓和材质；不是朝向摄像机的粒子贴片。
- 成窍后继续展示已有分层山海异象。原有灾劫三维模型保留。
- 每帧最多两个大型来源；体积云最多一个。普通网格17400个四边形顶点，低性能4872个顶点，低性能不绘制体积云和山海层。
- 客户端 legacyParticleEffects 默认false：关闭Photon装饰粒子与ClientFx本地粒子。服务端 legacyParticleAuras 默认false：关闭持续灾劫装饰粒子。攻击命中提示等既有服务器事件不属于此大型场景的材质和构形。
- cinematicEffects 控制实体宏大场景；enabled 总开关；screenEffects 只影响屏幕染色。画面染色已减弱，让模型轮廓与深度成为主体。
- 体积云新增VolumeScale换算：顶点还原与场景深度都转换到相同局部尺度；保持墙体遮挡，修正放大后的穿透/错位风险。

## 使用

安装 build/libs/shengxian-0.3.57.jar 后客户端可输入：

    /shengxiangrand show
    /shengxiangrand clear

show 在前方52格生成持续45秒的本地三维预览，不改世界状态、不消耗资源、不绕过升仙门禁。可走近或绕行观察形体。仪式及已同步的灾劫载体也会自动驱动实体场景。
