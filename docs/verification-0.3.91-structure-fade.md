# 0.3.91 玩家进入结构层内部的观感修复

日期：2026-11-02。针对"玩家在体内就很丑"的问题。

## 问题

0.3.90 的实体结构层（三层华盖、螺旋气帘、法阵环）是为远景构图设计的。玩家飞到华盖下方或进入气帘内部时，看到的是这些薄面片的背面、内壁和断裂边缘，视觉上像碎掉的笼子，比体积云本身更难接受。

## 处理

在 GrandRitualRenderer 中按相机到来源的距离淡出结构层：

- 距离 <= 24 格：结构层 alpha = 0，完全隐藏，只剩体积云。
- 距离 24–48 格：线性平滑过渡。
- 距离 >= 48 格：结构层完整显示，保留华丽远景。

结构层 alpha 仍乘以来源强度，低性能模式和零强度逻辑不变。体积云本身不参与这个淡出，近距离仍保留柔和云体。

## 边界

淡出阈值是游戏表现参数，不是原著规则。实际游戏内还需要用 /shengxiangrand show 走近确认过渡是否自然；如果希望更早隐藏，可把 24/48 改为 32/64。
