# 代表仙蛊实现验证记录

日期：2026-10-30。依据已通过的增强版设计规格完成本轮代码，当前源码尚未升版或打包。

## 已实现

- 定仙游：8 个安全落点，默认蓄力 60 tick；移动和受伤不打断。传送前复核所持物品、维度、落点、安全性及仙窍权限；成功后扣 3 仙元，默认冷却 200 tick。
- 人如故：自身或 24 格内可见玩家，可恢复 100 tick 内记录的生命状态，并处理期间新发生的燃烧、中毒、凋零；按目标限频，成功扣 2 仙元，默认冷却 60 tick。
- 江山如故：仅在本人仙窍内对 32 格范围使用。可选开启的「灾毁留景」默认关闭；仅记录符合白名单、确实被自然爆炸破坏的方块，不产生掉落。记录保留 10 分钟；单次最多恢复 1024 格，分批执行并受全局预算限制；成功扣 5 仙元，默认冷却 200 tick。
- 三件物品都是可重复催动的独立物品；共享服务端事务、扣费、并发锁及参与者回执。新增状态 schema 11，操作回执支持安全分块保存；旧状态可迁移，异常或不确定操作保持隔离。
- 灾毁留景始终是单独 opt-in；原有升仙 readiness 仍为空集。

以上数值均是游戏参数，不声称是原著中的数值规则。

## 验证证据

- FrameworkTest：200 项通过。
- SourceCheck：完整 Java 源码编译通过；8 个原有催动钩子、代表仙蛊与地形资源的 70 项静态检查通过。
- NbtCheck：新增可重复仙蛊事务的 23 项压缩 NBT 检查通过；旧有境界、失败、灾劫、反噬及碎窍回执检查也通过。
- 独立最终审查发现三项重要问题和一项次要问题，均在本轮修复并回归：大地形载荷的 NBT UTF 长度上限；多人操作开始前的全员来源回执预检；已确认回执的重复写入；访客/护道者在仙窍权限内使用定仙游标记的路径。
- 隔离 NeoForge 21.1.263 / Java 21 服务端烟测成功：三件物品注册，两个地形 mixin 应用，仙蛊目录及物品参数可解析，普通 TNT 爆炸路径返回成功，服务端退出码 0 且干净停服。烟测日志：build/representative-gu-smoke-7af17d328bfb4fb58404b3c9f90c43f4/verification.txt。
