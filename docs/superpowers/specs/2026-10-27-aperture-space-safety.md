# 仙窍共享维度安全设计

## 目标

让玩家留在自己获准访问的 16×16 地块内，阻止访客和护道者改动方块，并在地块首次生成前确认目标区域为空。已有地块认领关系仍是唯一归属来源；异常或孤立地块继续保留，不自动回收。

## 设计

- 纯 Java 核心实现地块几何和位置归属规则，采用左闭右开的 16×16 边界。
- 服务端持续检查处于仙窍维度的玩家；越界、未认领或权限已撤销时将其送回记录的返回点。
- 只有主人可破坏、放置、交互、投掷和拾取；访客/护道者即使被服务器显式启用也为只读，且默认关闭。掉落物记录所属地块，跨入另一已认领地块时移除。
- 玩家攻击、投射物、受击伤害和爆炸影响只在发起/落点所属的同一已认领地块内结算。
- 首次生成平台前检查全部落脚区块为空；任何占用都拒绝进入，不覆盖世界内容。
- 管理员命令和控制台不属于普通玩家隔离边界；不宣称维度级私有隔离。

## 验收

核心测试覆盖四边界、相邻地块间隙、负坐标、非法地块和授权判断。全源码在 Java 21 / NeoForge 21.1.263 编译通过。
