# 0.3.90 华丽结构层

日期：2026-11-02。针对"为啥不能精细华丽一点"的结构层升级。

## 新增内容

- OrnateStructureMesh：纯几何实体结构层，不使用粒子或贴片。
  - 三层环形华盖（半径46/56/66，y=86/98/110），每层36段波浪外缘环面，双面绘制。
  - 8条螺旋气帘从华盖下缘（y=84）垂落到地面（y=4），半径随高度波动24-40，宽度±3.2。
  - 云眼处2个金环（半径15/22，y=88/90）。
  - 地面法阵环2圈（半径26/36，y=1.2/2.0），缓慢正反旋转。
- 专属纹理 ornate_gilt.png：青玉底色+鎏金云纹+三层同心金弧+星辉，256x256 无缝平铺。
- 渲染顺序：体积云先合成，结构层后画，保证华盖/气帘/法阵在云体前面清晰可见。
- 低性能模式：华盖20段、气帘4条、法阵20段；正常2832顶点，低性能1744顶点。

## 渲染集成

- GrandRitualRenderer 在 AFTER_WEATHER 阶段先调用 renderTempest，再用 entityTranslucent 纹理画结构层。
- 结构层跟随来源位置，用世界时间驱动旋转和波动；强度钳制0-1，零强度不输出顶点。
- 三种调色板：0 青/玉/金，1 血红，2 紫金。

## 验证

- VerifyOrnateMesh PASS：high=2832 low=1744 顶点；有限值、单位法线、±78边界、y 0-130、UV范围、三调色板、强度钳制、零强度无输出、确定性、极端时间戳。
- GPU 预览通过：体积云5组视角遮挡测试 + 结构层叠合渲染。
- 修复：PreviewOrnate 的 view 矩阵被体积云清零平移分量，导致结构层画到屏幕外；已用 clone() 隔离。
