# 0.3.38–0.3.39 验证记录：界面重绘（玄墨金线）

日期：2026-11-01。用户反馈"太丑"，整个 `QiControlScreen` 视觉重做。

## 设计

原版是浅黄面板 + 土黄文字 + 灰色方块，风格与题材脱节。新设计走**玄墨金线**仙侠风：

- **面板**：深墨底（两层墨色叠加）、金色双线勾边、四角金色角花、标题下金线分隔
- **配色**： parchment 米白正文、哑金次级文字、玉色三气（天青 / 地青瓷 / 人赭）
- **页签**：当前页前加 ◆，激活态由可用性表达
- **纳气小游戏**（重画核心）：
  - 玉色渐变气条 + 金色条头，0..64 映射满格
  - 气条下方独立速率轨，**金菱滑钮**（菱形绘制）
  - "劫"字风险槽：玉绿 → 琥珀 → 血红三段变色（风险/12）
  - 失衡时气值与气条转红
  - 按钮组下移避开文字重叠（0.3.39 修正）
- 全部文字改用主题色；状态行金色 + 上方金晕线

## 实现

`QiControlScreen.java` 单文件：新增 `drawPanel`/`drawCorner`/`drawDiamond` 与主题色常量；`renderQi` 重写；命中检测跟随新几何（`trackLeft = left+64`，宽度 = panelWidth−128）；其余页文字统一换主题色。
