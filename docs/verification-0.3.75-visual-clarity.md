# 0.3.75 云体清晰度调整

日期：2026-11-02。针对“雾感很重，让他明显一点”的调整记录。

## 改动

- 全屏雾色上限从 0.76 降到 0.38，减雾模式从 0.20 降到 0.16。
- 雾色混合从 strength 降到 strength*0.42；屏幕渐变透明度从 strength*20 降到 strength*8，地表色带从 0.55 降到 0.35。
- 云体边界由软过渡改为 smoothstep 收紧，提高云体密度对比和自阴影强度。
- 环境光先压低以增强体积，再补回中间调，避免变成纯黑团块。
- 修复云体包围盒的矩形缺口：体积云使用只画背面的裁剪时，正对镜头的中心区域会漏出背景。渲染类型改为双面绘制（face none）。这是本轮实机预览中发现的真实问题，不是调色问题。
