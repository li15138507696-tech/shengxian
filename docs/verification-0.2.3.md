# 0.2.3 三气控制会话门禁

## 改动

- `/shengxianqi` 与 K 键界面现在只会为已有且处于 `ABSORBING` 的服务端会话登记调气意图。
- 没有会话、会话阶段不符、存档不可读时会立即拒绝、停止残留光效并反馈，不会留下每秒重试的意图。
- 三气模拟发生存档错误时停止当前意图并提示玩家；玩家登出、服务器停服或再次启动时清空内存控制状态，避免重连后自动恢复旧意图。
- 不开放 `StartGate`，不创建会话、不写入本体字段，也不改变三气公式和原著规则。

## 核验范围

- Java 21 编译、JAR 元数据/资源校验；确认 0.2.2 中的 Veil 4.5.2 嵌套包与 SHA-256 保持有效。
- 未运行测试套件、多人场景或游戏客户端；调气控件仍需在有效 `ABSORBING` 会话中进行实机验收。
