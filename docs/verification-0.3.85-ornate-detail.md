# 0.3.85 云体细节层

日期：2026-11-02。回答“为什么不能精细华丽一点”的实现记录。

## 为什么之前看起来不精细

前几版走的是纯体积云路线：没有粒子、没有贴图贴片，所有细节都来自三维密度场。为了控制采样成本，噪声只有四层、频率偏低，云体边缘又被平滑过，所以远看只剩大块明暗，容易像一团软云或蘑菇。粒子被否掉后，华丽感不能再靠大量小贴片堆出来。

## 本轮增加

- 增加域扭曲的多尺度湍流：大团云、细碎侵蚀和丝状结构分开计算。
- 密度中混入 ridged noise，形成细丝、卷须和内部金纹，而不是均匀噪点。
- 金纹只保留在稀疏高值区域，避免变成满屏金色裂纹。
- 保留 130 格上下跨度、双面绘制和原有遮挡。
- 体积采样仍为 64/36 步，未把 GPU 成本抬到不可用。

## 还没解决的部分

这版仍然是“云体表面更细”，不是“结构更华丽”。要真正达到华丽，需要再加一层实体结构：分层云冠、飘带、雷纹或环形法阵，用真正的几何/体积混合，而不是继续增加噪声。单纯把噪声频率拉高只会变脏，不会变华丽。
