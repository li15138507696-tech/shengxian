# 0.3.68–0.3.69 灾劫载体血量与摧毁结算

日期：2026-11-02。用户要求：载体血量至少百万以上。

## 实现

- `core/CalamityCarrierStats`：每类灾劫的血池上限（全部 ≥ 1,000,000）、玩家破防倍率、紧凑显示（1.50M / 1.10M）。
- `server/CalamityCombatService`：按载体实体 UUID 维护血池；受击扣血、刷新同步名、受击粒子与音效；血量归零执行摧毁（爆炸粒子 + 凋零死亡音 + 移除实体 + 日志）。
- 真实灾劫载体：血量由战斗层权威结算，只有打空血池时才通过 `strikeTribulation(Integer.MAX_VALUE)` 提交一次销毁，避免每个 tick 都改持久状态。
- 无主测试载体：同一血池，无持久状态。
- 测试钩子：`/shengxiantest hit [伤害]` 直接用指定伤害打击附近测试载体，并回报剩余血量或“被摧毁”。

血池数值（单位：点）：

| 灾劫 | 血量上限 |
|---|---:|
| 柳风天灾 | 1,200,000 |
| 独角峥虎地劫 | 1,500,000 |
| 音磬天灾 | 1,100,000 |
| 荒兽地劫 | 2,000,000 |
| 血雨灾劫 | 1,300,000 |

玩家武器伤害乘以 1000 后结算（`PLAYER_DAMAGE_SCALE`），所以普通武器也能推动百万血条。

## 实机验证

- 生成独角峥虎测试载体，命令回报：150 点打击 → **剩余 1.35M HP**；再来一次 → **1.20M HP**；5000 点打击 → **被摧毁**，服务端日志 `Calamity carrier ... SINGLE_HORNED_TIGER was destroyed`。
- 截图 `docs/art/ingame-chimes-1.10M-hp.png`：音磬天灾的原创模型在实际世界中渲染，名牌显示 **1.10M HP**。
- 截图 `docs/art/ingame-beast-and-bloodcore.png`：荒兽（骨甲+蓝色裂隙）与血雨核心模型实际渲染。
- Framework 测试 209 通过 / 0 失败，其中新增“每类灾劫血量不低于一百万”。

## 限制与未完成

- 血池目前只在内存中：服务器重启会把受伤的载体恢复满血（持久单位不变，仍可被重新打空）。重新登录不影响。
- 预警环仍未取得可视截图：环由服务端尘埃粒子绘制，代码与打击同一条 tick 路径，但我没有抓到清晰画面。
- 摧毁没有专用死亡动画（用的是爆炸粒子 + 音效 + 立即移除）；模型自带的 death 动画尚未接线。
- 投射物、血池区域、屋顶遮挡专项用例仍缺。
