# 三气引擎参数（游戏映射）

日期：2026-10-25。QiParameters.standard() 的每个数值都是**游戏化参数**，不是原著常数。证据编号只约束机制形状，具体速率/阈值需要后续实机平衡。

## 机制依据

| 机制 | 证据 | 说明 |
| --- | --- | --- |
| 碎窍后天地二气自来、人气外显，本人持续调和 | CANON-001/002 | 三气在身外交汇；失衡稍偏即可致命 |
| 人气偏重自爆、天气偏多消融、地气偏浓石化窒息 | CANON-002 | 三种方向独立结算，不用总成功率 |
| 多吸天地二气提高未来成就，贪多致败 | CANON-003 | 吸入量影响未来底蕴（尚未接福地） |
| 交感窗口内直接体悟，分心有风险 | CANON-004 | 仅窗口内可领悟；求知不暂停气机 |
| 人气来自自身积累，不是凭空产生 | CANON-002/003 | 有限 humanReserve；释放不创造 |

## 当前参数

| 字段 | 值 | 含义 | 备注 |
| --- | --- | --- | --- |
| ambientMaxHeaven/Earth | 120 | 外部二气储量上限 | 缩尺单位 |
| ambientRegenPerTick | 1.5 | 每个模拟步恢复量 | 默认每 20 个服务端 tick 推进一步；与位置/天气尚未联动 |
| maxAbsorbHeaven/EarthPerTick | 4.0 | 每个模拟步最大吸入 | 受客户端 0..1 意图缩放 |
| maxHumanReleasePerTick | 3.0 | 每个模拟步最大人气释放 | 只从储备扣除 |
| balanceTolerance | 0.18 | 偏离均值的容差 | 不是原著比例；1:1:1 只是抽象 |
| riskGainPerTick | 0.8 | 每个模拟步的失衡风险 | 只对超出容差的方向增加 |
| riskDecayPerTick | 0.35 | 每个模拟步的平衡衰减 | 全零气机不衰减 |
| riskLimit | 12.0 | 致命阈值 | 达到后提交 FAILED |
| windowMinQi | 20.0 | 窗口所需的每项最低气量 | |
| windowTicksRequired | 40 | 窗口持续模拟步数 | 默认步进间隔 20 个服务端 tick，约 40 秒 |
| insightPerWindow | 2 | 每窗领悟额度 | 知识池尚未实现 |
| distractionRiskFactor | 0.9 | 求知时的额外风险系数 | 加到三向风险 |

## 未实现/待核

- 位置、维度、天气、时间对二气供给的影响未接。
- 人气上限/恢复规则未核；0.2.4 原型曾在升仙开始时以魂魄、体质、气运作 60–120 的有界游戏映射，之后只从 humanReserve 释放消耗，不读取派生 renqi。该加权公式未经原著赋值，也未实机平衡；0.2.5 已封闭新升仙入口。
- 领悟额度与知识条目、蛊方、残方的对应未核，GAP-003。
- 失衡数值、容错时长、输入频率均为待实机调整的游戏参数；不能宣传为原著数字。
