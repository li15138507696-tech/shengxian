# 仙蛊证据与实现边界（0.3.21）

日期：2026-10-29。本页记录仙蛊最小闭环读到的原文事实、未核部分与代码边界。

## 原著已核（CANON-009）

译本第 688 节《黑楼兰升仙（下）》：

- 黑楼兰以**六转排难仙蛊**的「排难之光」逐一消灭八道音磬。
- 强行催动导致双眼爆裂、道痕残留眼窝无法复原。
- 排难仙蛊最终**自爆粉碎**。

## 未核（不得写成规则）

- **炼成**：没有任何读到的章节描述仙蛊如何炼成、需要什么材料或条件。因此本模块不提供炼制，只能由管理员发放。
- **唯一性**：GAP-004 明确「仙蛊唯一性判定」未核。本模块只按会话（一个空窍）限制持有数量，不是世界唯一。
- **双眼爆裂**：这是黑楼兰强行催动的个例，不是通用代价；未实现，也不作为默认后果。
- **其他仙蛊**：目录只有 `pai_nan` 一条，没有凭空补条目。

## 实现（游戏参数部分）

| 项 | 值 | 性质 |
| --- | --- | --- |
| 催动消耗 | 5.0 青提仙元 | 平衡参数，不是原著数字 |
| 效果 | 摧毁一个活动灾劫载体 | 对应 CANON-009 的「排难之光」 |
| 代价 | 该仙蛊消耗一份（owned/used 计数 +1） | 对应「自爆粉碎」 |
| 唯一性 | 每个会话同时最多持有一份 | 游戏映射，非世界唯一 |

持有记录写进会话的**追加式效果账本**：`xiangu:owned:<id>:<n>` 与 `xiangu:used:<id>:<n>`，持有 = owned > used。这样既满足账本只能增长的不变量，也允许管理员在使用后再次发放。
