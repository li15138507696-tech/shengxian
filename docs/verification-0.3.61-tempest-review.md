# 0.3.61 云壁视觉评审

日期：2026-11-02。本轮是对用户否定0.3.57美术方向后的重做，不作为美术终稿或完整升仙开放声明。

## 改动

- 默认大型天象移除GrandRitualMesh硬质三色管、悬空圆环和盆状岩脊；保留原实现供历史验证，但当前主路径不绘制它。
- 新TempestVolumeMesh仅提供208×72×208格的光线步进包围盒。实际云体由三维密度场生成，没有用盒子表面假装云。
- 大云壁、下方汇聚云流和近地尘雾使用分层噪声、光程消光、自阴影和低饱和颜色。高性能64步、低性能36步且减少自阴影计算；未做正式帧率验收。
- 保留原灾劫模型、成窍山海异象和服务器阶段逻辑；本轮不改readiness门禁。
- 0.3.61本地show命令在前方80格的已加载地表生成预览，持续180秒，避免把地表尘雾挂在飞行角色的高度。clear清除。

## 实机发现与修复

0.3.59实际游戏出现原版方块云把新云壁覆盖成大块缺口的问题。检查运行依赖中LevelRenderer字节码确认：AFTER_PARTICLES在renderClouds之前；仅用该阶段绘制体积云会被后续原版云覆盖。

0.3.60开始先在AFTER_PARTICLES复制场景深度，再在AFTER_WEATHER叠合体积云。使用已复制深度裁剪地形，避免把原版云的几何代理表面当成不透明障碍。实际保留原版云开启的0.3.60远景和仰视截图不再出现前述大块缺口。

实机预览在独立build/visual-review-20261102目录运行。仅该目录加载额外VisualReviewDriver测试模组，自动释放按键、固定视角并通过Minecraft Screenshot接口保存AFTER_LEVEL画面；测试驱动只设置本地预览和摄像机，不改变玩家升仙阶段或给出成功结果。正式shengxian产物不包含该驱动。服务器为隔离test-server、NeoForge21.1.263、shengxian0.3.57；0.3.61客户端只做渲染和本地预览，未用这种版本组合宣称玩法流程验收。
