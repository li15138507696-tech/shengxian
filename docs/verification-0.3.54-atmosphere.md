# 0.3.54 Photon 天地变色

2026-11-02

## 改动

新增客户端 RitualAtmosphere，配合现有 Photon 灾劫粒子和升仙仪式同步表现。

- 仪式阶段推进环境强度：准备弱、碎窍增强、纳气加深、开窍成窍最强。
- 读取客户端已同步的灾劫载体名称。血雨偏暗红，风灾偏青绿，音磬偏紫，荒兽偏土金；仪式使用青蓝远景与金色近景。
- ComputeFogColor 混合远景雾色；RenderGuiEvent.Pre 用低透明度渐变覆盖场景，HUD 在其后绘制。
- 最强附近来源决定强度，多人不会累加亮度。64 格范围内平滑衰减，进入、离开及结束采用逐 tick 淡入淡出。
- 换世界立即清除状态；水下、熔岩内保留原有雾色，打开菜单时不绘制屏幕染色。
- 尊重 enabled、cinematicEffects、screenEffects、reducedMotion、lowPerformance。screenEffects 关闭仅取消屏幕层，雾色仍由 cinematicEffects 控制。
- Photon 新建发射器时，低性能使用 35% 粒子预算，低动态使用 65%；正常模式保持原有预算。变更后重新触发特效生效。
- 纯客户端视觉效果，不修改服务器天气、时间、伤害或灾劫规则。
