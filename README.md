## 已有原型与安全边界

- 世界会话持久化、阶段修订与重复动作防护；三气和灾劫调度仍是原型，不能单独视作可玩的原著流程。
- K 键“升仙卷 / 三气调和”页面与 Veil 4.5.2 三气效果；玩家动作由服务端校验。
- 已形成仙窍拥有面积、时间比、仙元账本与独立空间；访客/护道人默认关闭，配置开启后仍只读。
- 共享仙窍地块只允许主人建造、投掷和拾取物品；掉落物带有地块归属，进入另一已认领地块时移除。平台生成前检查地面并拒绝覆盖已有方块；玩家攻击、投射物、受击伤害和爆炸限制在同一已认领地块。
- 玩家事件保护不拦截管理员命令、控制台命令或其他模组直接写世界的操作。
- 人气原型不读取本体派生 `renqi`；其储备映射和三气参数不属于原著常数。
- 本命蛊投入时，完整物品先写入世界托管账本，再从背包移除；未提交中断按会话阶段恢复。0.3.1 已将成窍后的本命蛊标为嵌入托管；在没有普遍依据时不伪造返还或升炼结果。打包与隔离服务端验证见 docs/verification-0.3.1.md。
- readiness 门禁关闭或失败原因不是唯一且明确的三气失衡原因时，旧失败记录只保留并告警，不向本体写失窍/死亡。即使原因符合，CANONICAL_FAILURE 能力仍关闭：死亡副作用与持久确认之间的崩溃窗口尚未解决。后续合法降转不会被升仙记录自动覆盖。

## 仙窍过渡

进入或离开仙窍时，目标玩家客户端播放 16 tick 的水墨水流过渡；附近玩家仍收到原有音效和粒子。效果使用 Veil 4.5.2，反射适配不可用时显示 16 tick 的原版颜色蒙层回退。该视觉效果此前已随 0.2.6 打包；0.3.7 客户端确认加载 Veil 着色器管线，升仙转场因门禁关闭未触发。验证记录见 docs/verification-0.3.7.md。
## Veil 兼容性

当前选择**固定渲染环境**：保留嵌入的 Veil 4.5.2。Veil 4.5.2 与 Embeddium、Rubidium、Celeritas 不兼容，包含这些渲染优化模组的整合包不得与本版本同时使用。若要面向所有整合包，需要改为可选客户端依赖、移除嵌入并增加无 Veil 回退；本版本不承诺该模式。

## 构建

`build.ps1` 的 `Build` 会运行核心测试、编译、执行压缩玩家 NBT 校验、打包并检查产物。复核当前源码和 0.3.92 产物：

```powershell
pwsh -NoProfile -File .\build.ps1 -Action SourceCheck
pwsh -NoProfile -File .\build.ps1 -Action NbtCheck
pwsh -NoProfile -File .\build.ps1 -Action Verify -ModVersion 0.3.92
pwsh -NoProfile -File .\build.ps1 -Action Clean
```

Test 单独运行纯 Java 核心行为检查；SourceCheck 编译完整 NeoForge 源码、核验四个实际本体注入点与压缩玩家 NBT，但不生成 JAR；NbtCheck 单独运行玩家存档 NBT 核验。0.3.92 产物路径为 `build/libs/shengxian-0.3.92.jar`。构建从本机 profile 读取 NeoForge 依赖，并将 Veil 4.5.2 作为 Jar-in-Jar 内嵌。

### 产物清理（构建后自动执行）

- **每次构建的暂存目录会自动删除。** 每次调用都会在 `build/runs/<GUID>/` 建一份编译输出与打包候选，`Build`/`Test`/`SourceCheck`/`NbtCheck`/`Verify` 成功收尾时清空 `build/runs`。**失败的那一次故意保留**，便于排查。
- **发布产物保留最近 3 个版本。** 旧 jar 无法重建（源码不随版本留存），因此不做全量删除；`build/libs` 里只保留最新的 3 个 `shengxian-x.y.z.jar` 及其 `.sha256`，更旧的由成功构建自动剪枝。内嵌 Veil jar 与 `metadata.json` 属于输入，永不剪枝。
- `-Action Clean` 手动回收积压：清 `build/runs`、删除 `.cache` 本体 jar 的可重生成副本（`build/upstream-extract`、`build/upstream-classes`），并按上面策略剪枝产物。保留 `.cache` 本体 jar、`build/optional-deps`（Photon/LDLib2 可选依赖）、`build/decompiled` 与 `build/refs`（审计证据）。
- 实测把 `build/` 从 3.65 GB 降到约 35 MB（清掉 170 个历史暂存目录、25 个一次性验收/测试环境、89 个旧版本产物），构建与校验全部照常通过。


离线检查着色器并生成合成背景预览：pwsh -NoProfile -File ./tools/verify-fx.ps1。此工具不加载Minecraft或服务器。

离线网络回环：pwsh -NoProfile -File ./tools/verify-protocol.ps1，不会建立游戏连接。
